# Project history

OpenCamInterop began as an interoperability layer inside
[KalyteraSystems/IPCamLapse](https://github.com/KalyteraSystems/IPCamLapse). It was
split into this focused repository once the contracts, offline EventLab, fixture
manifest, and standalone project governance were ready to evolve independently.

## Preserved history

This repository was extracted from the `OpenCamInterop/` directory at IPCamLapse
commit [`fa5b221`](https://github.com/KalyteraSystems/IPCamLapse/commit/fa5b221e72cb8541e908a266a13d6440dbf27f9e)
with `git subtree split`. The split preserves the commits that changed that
directory while intentionally excluding unrelated IPCamLapse files.

The source milestones are:

- [PR #37](https://github.com/KalyteraSystems/IPCamLapse/pull/37), merged as
  [`c08b33d`](https://github.com/KalyteraSystems/IPCamLapse/commit/c08b33d2f93ea34eb10896aa4fd56e940a7648e1),
  introduced the first OpenCamInterop contracts and adapters.
- [PR #40](https://github.com/KalyteraSystems/IPCamLapse/pull/40), merged as
  [`fa5b221`](https://github.com/KalyteraSystems/IPCamLapse/commit/fa5b221e72cb8541e908a266a13d6440dbf27f9e),
  added the offline EventLab and prepared the standalone project.

The original pull-request discussions and checks remain in the IPCamLapse
repository; the relevant source history continues here.
